To honestly measure progress, separate multiple-choice knowledge from real code execution. LOOP has no Python runner or GitHub access to inspect your projects, so task completion is **self attested**. The diagnostic samples only 2 questions per skill and must never be interpreted as an objective professional certification. The adaptive algorithm uses the diagnostic as a suggested starting point without granting mastery of skipped stages.
